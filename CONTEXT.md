# Tidder

A desktop Reddit client. This glossary pins down the words used for
Tidder's own concepts, and keeps them apart from Reddit's.

## Language

### Feedback

**Toast**:
A short, transient message Tidder shows in the corner of the window
to report the outcome of something the user did (success, warning or
error).
_Avoid_: Notification, snackbar, alert

**Notification**:
An item in the user's Reddit inbox (replies, mentions, messages),
as Reddit defines it.
_Avoid_: Toast, alert
